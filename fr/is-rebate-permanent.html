Futures : tout dépend du code, normal ou Super Parrainage

C'est là que la différence est grande.

Code de parrainage normal : le remboursement Futures dure 12 mois à partir de l'ouverture de votre compte Futures. Ensuite, c'est fini.

Code Super Parrainage : Binance supprime la limite de 12 mois quand le taux de commission Futures du parrain est de 30 % ou plus, c'est-à-dire le niveau Super Parrainage.
